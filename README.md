### 🏓 卓球デジタルスコアボード Pro

スマホやタブレットを横向きに置いて、練習試合や大会でガチで使える、フルスクリーンのデジタルスコアボードアプリです。
StreamlitとPythonの最新技術を駆使し、スポーツの現場での操作性と美しさを徹底的に追求しました。 

### ✨ 主な機能とこだわり

* **洗練されたダークモード**：体育館の照明下でも見やすく、目に優しいデザイン
* **公式ルール完全準拠**：11点先取、デュース（2点差がつくまで自動継続）のロジックを搭載
* **スマート演出**：10点以上の緊迫した局面（クライマックス）でスコアが自動的に黄色く変化
* **ワンタップ・コートチェンジ**：名前・スコア・ゲーム数・サーブ権がボタン一つで完璧に反転
* **レスポンシブUI**：無駄な余白やスクロールを一切排除し、1画面にすべての操作を集約
